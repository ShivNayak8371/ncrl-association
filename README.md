# NCRL Welfare Association Portal 🏠
**Madhu Reddy Layout, Bengaluru**

This is the official web portal for the **New City Regency Layout (NCRL) Welfare Association**. It serves as a digital hub for residents to stay updated on community notices, events, and a streamlined system for membership registration.

## ✨ Key Features
* **Dynamic Notices & Events:** Admin-managed updates for the community.
* **Membership Registration:** Integrated form that sends data directly to a Google Spreadsheet.
* **Admin Dashboard:** Secure login (`admin123`) to manage content and export member lists to Excel.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing using Tailwind CSS.
* **Community Gallery:** A visual showcase of layout updates and events.

---

## 🛠️ Technical Stack
- **Frontend:** HTML5, Tailwind CSS, Inter Fonts.
- **Backend Integration:** Google Apps Script (Web App).
- **Database:** Google Sheets (via Fetch API).
- **Hosting:** GitHub Pages.

## ⚙️ Administration
To manage the site:
1.  **Login:** Click the "Admin" button in the navigation bar.
2.  **Password:** Default is `admin123`.
3.  **Features:** * Add/Delete Notices and Events.
    * Add/Delete Gallery Photos.
    * **Export Member List:** Downloads the current registration database from Google Sheets as an `.xlsx` file.

---

## 📝 Maintenance
To update the site content or code:
1.  Edit the `index.html` file.
2.  Commit changes to the `main` branch.
3.  GitHub Pages will automatically deploy the updates within 1–2 minutes.
